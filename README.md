# Akky – Auction House

An auction site made for the Noroff Semester Project 2, using the Noroff Auction API.

**Live site:** https://akky01.netlify.app

## Features

- Register and log in with a stud.noroff.no email
- View, search and open listings (also when logged out)
- Create, edit and delete your own listings
- Place bids on other listings (logged in only)
- View and edit your profile (bio, avatar, banner) and see your credits

## Built with

- HTML, JavaScript (ES modules)
- Tailwind CSS
- Vite
- Noroff API v2
- Netlify

## Run locally

1. Clone the repo
2. `npm install`
3. `npm run dev`
4. Open http://localhost:5173
